# 异界-落水狗 · 手机版

这是从原版复制出来的独立手机适配版本，原目录中的电脑版文件没有改动。

## 怎么运行

手机浏览器不能像电脑一样稳定地直接打开本地 HTML，建议把整个 `手机版` 文件夹放到一个静态网站目录 / 局域网服务器上，然后用手机浏览器访问 `index.html`。

电脑上快速预览（在 `手机版` 目录内执行）：

```bash
python -m http.server 8080
```

然后手机和电脑连同一个 Wi-Fi，访问：

```text
http://电脑的局域网IP:8080/
```

也可以直接在电脑浏览器里双击 `index.html` 预览；宽度大于 1024px 时会自动回到接近电脑版的布局。

## 手机版做了什么

- **竖屏单列布局**：顶部状态条、地图、附近角色、剧情记录、交互按钮、底部导航依次排列。
- **横屏布局**：自动切换为「左地图 + 右信息/操作」两栏，战斗界面也会变成左右分栏。
- **触屏地图**：单指拖动、双指缩放、点按节点移动；右上角保留 `＋ / − / ⌂` 缩放与回中按钮。
- **关闭下拉刷新**：页面根节点关闭 overscroll 回弹，内层列表使用 `overscroll-behavior:contain`；同时拦截“所有内容已到顶时继续向下拖”的 `touchmove`，避免打包成 App 后误触 WebView 原生下拉刷新。
- **战斗界面分行固定**：敌方前/后排、我方前/后排、日志、技能、道具/跳过按钮各有明确的最小高度，屏幕高度不足时按比例压缩而不是把后排压扁；技能区固定为一条可横向滑动的技能条，最多两行技能说明，不会再和后排或底部按钮叠在一起。
- **严格前四后三阵型**：我方队列统一为前排 4 席、后排 3 席并居中，每排最右侧 1 席为宠物位；主界面队列面板改为全屏居中面板，战斗中的我方队列也按同一阵型排列。
- **地图层级按钮上移**：世界 / 城镇 / 街道按钮移到地图上方，不再悬浮覆盖地图节点；地图缩放按钮也做了缩小。
- **行囊与角色面板紧凑化**：金币移到「行囊」标题后，搜索框和分类按钮缩小；角色简略卡片、纸娃娃空方格与属性格在竖屏下压缩，减少滚动。
- **地图缩放保持**：缩放后点击节点移动不再回到固定比例，保留玩家当前的缩放级别。
- **连续赠送**：送礼面板不再每送一次就自动关闭，可连续赠送，由玩家手动关闭。
- **全屏 / 底部抽屉弹窗**：行囊、角色、任务、着装、交易、剧情等界面按手机屏幕重排，内容可滚动。
- **触控尺寸**：主要按钮不小于 44px，输入框字号 16px，避免 iOS 聚焦时自动放大。
- **安全区适配**：支持刘海屏 / 底部手势条的 `safe-area-inset`。
- **手机菜单**：右上角 `☰` 可保存、返回存档、查看称号、关于、打开调试面板；菜单里显示当前游戏时间。
- **调试面板**：从右上角菜单直接进入，跳过密码输入，全屏可滚动，方便在手机上测试角色、技能、物品、敌人、战斗和剧情。
- **调试面板增强版**：见下方「调试面板增强版」。
- **已移除编辑器代码**：手机版不需要 `editor.html`、`editor-modules/`、`designer-common.css/js`，已从本目录删除，不影响游戏运行。
- **桌面兜底**：用电脑浏览器打开时仍按原版 1920×1080 舞台缩放，地图控件也做了兜底排版。

## 改了哪些文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 手机端 viewport / 状态栏配置，地图悬浮控件、手机菜单、引入新样式和脚本 |
| `mobile.css` | **新增**，手机版全部布局、弹窗、战斗和横屏适配；含关闭下拉刷新、战斗分行与矮屏压缩 |
| `mobile.js` | **新增**，设备判断、关闭固定画布缩放、手机菜单、触摸细节、下拉刷新抑制 |
| `core.js` | 地图拖拽改为 Pointer Events（鼠标 + 触屏通用），加入双指缩放；手机端地图聚焦当前节点、预留悬浮控件安全区 |
| `debug-plus.js` / `debug-plus.css` | **新增**，调试面板增强（角色数值 / 装备技能挂载 / 物品 / 敌人模板 / 战斗 / 剧情 / 公式 / 补丁导出） |
| `data-config.js` | 战斗上限等常量改为可写（`let`），供调试面板运行时调参 |

其余 `data-*.js`、`battle.js`、`story.js`、`main.js`、`styles.css` 等游戏逻辑与数据均保持原样。

## 调试面板增强版

手机上从右上角 `☰` →「调试面板」进入。所有改动先在内存里生效：

- **角色**：点角色右侧「详细数值 / 挂载」可改等级、HP/MP、体力/精神基础值与成长、命中/闪避/暴击/暴伤、8 个装备槽、4 个技能槽、熟练度、职业/称号/被动/AI、掉落表。
- **地图挂载**：角色编辑页最下方可改角色所在街道格子，支持「移动到选中格 / 从地图移除」；玩家本人可「传送到选中格」。位置写入当前存档，刷新 / 读档后保留。
- **角色卡模板**：NPC / 敌人可切到「角色卡模板」编辑；模板改完点「应用到当前存档实例」，已生成的敌人立刻按新数值重算。
- **物品**：可改等级、价格、品阶、词条、装备部位、标签、职业限制、赋予技能、装备被动；支持「按品阶补满词条」「设为已设计」「发放 ×10」「直接穿上」。
- **合成**：新增合成表编辑页；可新建普通合成 / 品阶进阶、增删材料（最多 5 种）、改产出 / 品阶 / 金币，改动可随「导出修改」生成补丁。
- **敌人**：可按敌人 / NPC / 宠物筛选、搜索，直接编辑任意角色卡模板。
- **战斗**：列出全部遭遇战，一键开战；战斗中可改双方 HP/MP/攻防速、加减状态、敌方全体 1 HP / 击杀。
- **名称点击**：物品名、技能名在行囊 / 装备 / 商店 / 合成 / 战斗技能条 / 战斗道具 / 战斗掉落中统一可点击，打开详情；技能详情显示当前熟练度、下一级门槛与进度。
- **剧情**：剧情线下一节点 / 完成 / 重置、章节、flags 与 lineState 编辑。
- **数据**：角色属性公式、敌人档位模板、战斗上限、玩家初始值、自动时间，可实时改；还有「当前地图商人上架全部物品」和「商店显示全部物品（含未设计）」两个测试开关。模板改动可用「导出修改」生成 `data-debug-patch.js` 或 JSON，带回电脑版合并。

> 测试便利：和谐镇（新游戏起始地图）的商人 npc008 / npc019 默认已上架全部物品；其他地图可进「数据」页点「当前地图商人上架全部物品」。

## 存档说明

存档仍然使用浏览器 `localStorage`，按「域名 + 端口」隔离。换手机、换浏览器或换访问地址后，旧存档不会自动跟过去；需要迁移时，可在电脑版调试面板导出存档 JSON，再在对应环境导入。
